Como pasarela de pago, Quiero informar cuando una transacción sea rechazada, Para que el PMS pueda indicar al cliente que debe utilizar otro método de pago.
HU-04 — Procesar reembolso
Como pasarela de pago, Quiero procesar solicitudes de devolución de dinero, Para que el hotel pueda realizar reembolsos cuando corresponda.
HU-05 — Confirmar reembolso
Como pasarela de pago, Quiero confirmar que un reembolso fue realizado correctamente, Para que el PMS pueda actualizar la información financiera de la reserva.
HU-06 — Generar referencia de transacción
Como pasarela de pago, Quiero proporcionar un identificador único para cada transacción, Para que el PMS pueda mantener trazabilidad de los pagos.
HU-07 — Consultar estado de transacción
Como pasarela de pago, Quiero permitir consultar el estado de una transacción, Para que el PMS pueda verificar si un cobro está aprobado, pendiente, rechazado o reembolsado.
